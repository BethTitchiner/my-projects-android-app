# Release notes

## 8.0 — first GitHub release

- Priorities persist across dates, including completed and nested tasks, until manually removed.
- Previously selected tasks hidden by the old date filter reappear unless removed or deleted.

### Included features

- Reorder project cards on the landing page using long-press dragging and a grey insertion line.
- Includes reorderable flowchart steps, tasks, subtasks and daily priorities.
- Create standalone priority tasks with nested subtasks.
- Centred priority context labels and thicker, higher-contrast progress bars.
- Encryption-required Android system cloud backup and a backup-settings shortcut.
- Teal MP app icon.

Requires Android 8.0+. Automatic encrypted cloud backup requires Android 9+ and suitable device settings. Existing installations signed with the original key can update in place. Export a backup first.
